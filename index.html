TEAMS USAGE METRICS

Filter by Division or Role to see metrics and the mean for that group. Pick a user (or click a row in the table) to see where their value falls on the group curve compared with the group mean.

Role rows show per-user averages (Meeting Count is a total). Click a role to draw that role’s curve; expand it and click a user to mark that user on all three curves.

Synthetic data. Every name, ID and number on this page is invented for demonstration. It is a hand-built HTML recreation of a Power BI report; the calculations mirror the report’s DAX.

How the curves are calculated 
Mean_ScreenShr  = CALCULATE( AVERAGE(Teams_Metrics[ScreenShare_hrs]),
                    ALLEXCEPT(Teams_Metrics, Teams_Metrics[ROLE], Teams_Metrics[DIVISION]) )
stdDev_ScreenShr = CALCULATE( STDEV.P(Teams_Metrics[ScreenShare_hrs]),
                    ALLEXCEPT(Teams_Metrics, Teams_Metrics[ROLE], Teams_Metrics[DIVISION]) )

X table  = integers from FLOOR(mean - 3*stdDev) to CEILING(mean + 3*stdDev)
f(x)     = EXP( -(x - mean)^2 / (2 * stdDev^2) ) / ( SQRT(2*PI()) * stdDev )

Mean_*_INDIC = AVERAGE(metric) for the selected user (same role and division context)
